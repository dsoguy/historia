# First-session bootstrap prompt

Initialize this mosaic repository as a new AI-assisted working session according to framework/AI_OPERATING_MODEL.md.

Do not rely on prior chat history as authority and do not infer my Operating Scope or namespace ID.

First read the stable Framework contracts required by the operating model. If I have not already explicitly supplied an Operating Scope, ask me to select exactly one: FRAMEWORK, SHARED, or ARCHITECTURE.

If the selected scope is SHARED and I have not already explicitly supplied the Domain ID, ask for it. If the selected scope is ARCHITECTURE and I have not already explicitly supplied the Architecture ID, ask for it. If the selected scope is FRAMEWORK, no namespace ID is required.

After the scope and any required namespace ID are established, initialize the selected authority namespace and report the session state using the initialization response contract in framework/AI_OPERATING_MODEL.md before beginning substantive work.

# End first-session bootstrap prompt
